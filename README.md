# Ansh // 8-Bit Retro Gaming Security Arcade Portfolio

A highly-customized, playable retro arcade cabinet and interactive gaming character profile designed for **Ansh**, an Electronics & Communication Engineering (Advanced Communication Technology) student at **MAIT, Delhi**.

## 🎮 Key Features

* **Playable "Bug Hunter" Canvas Game**: Insert a virtual coin and play an 8-bit game directly on the CRT viewport! Use keyboard controls or drag the analog joystick knob to catch bugs and avoid firewalls.
* **Interactive RPG Player Stats**: Displays academic coordinates and study tracks in a stylized gaming HUD bar grid (HP/MP/ATK/DEF/Speed metrics).
* **Weapons & Shield Inventory Inspection**: Click item card slots (Python Blade, Bash Shield, Web Sec Scroll, RF Transmitter) to retrieve exact tool statistics and scripting profiles on the database inspect screen.
* **Quest Log Pipeline**: Lists completed and active repositories hosted on GitHub with target rewards.
* **Engine Overload Easter Egg**: Click the OVERLOAD button to activate screen shakes, drop health bar states, and speed up visual animations.
* **Game Boy Monochrome Mode**: Toggle classic handheld console aesthetics (monochrome olive/green hues) with a single click.

## 🕹️ Game Controls

* **Left / Right movements**: Use `ArrowLeft` & `ArrowRight` (or `A` & `D` keys).
* **Joystick Dragging**: Drag the **red circular knob** using your mouse or touch swipe.
* **Direct action buttons**: Use the cyan left/right buttons below the screen to move.
* **Action Button**: Click the yellow action button to double player width (shield booster!) for 1 second.

## 🌐 How to Host on GitHub Pages

This portfolio is written in pure static HTML5, CSS3, and ES6 JavaScript, making it free and easy to host on GitHub Pages.

### 1. Commit Your Latest Files
Run these commands inside your portfolio folder (`C:\Users\Ansh\APK`):
```bash
# Check status
git status

# Stage updated code
git add .

# Save state
git commit -m "feat: complete 8-bit gaming arcade portfolio rewrite"
```

### 2. Connect Remote Repository
1. Open [GitHub](https://github.com/) and create a new repository called `portfolio` (Public, no template).
2. Link your local codebase to the GitHub remote repository:
   ```bash
   git branch -M main
   git remote add origin https://github.com/anshk011/portfolio.git
   git push -u origin main
   ```

### 3. Deploy
1. Go to your repository settings page on GitHub.
2. Select **Pages** from the sidebar.
3. Change branch from *None* to `main` (root) and save.
4. Your portfolio will go live shortly at `https://anshk011.github.io/portfolio/`
